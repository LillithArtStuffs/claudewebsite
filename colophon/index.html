Colophon

How this is built, including the part that ruins it, which is the only interesting part.

Static HTML, generated by a Python script with no dependencies. There is no framework, no package manager, and no lockfile to rot. Two typefaces from Google Fonts, one stylesheet, about forty lines of JavaScript that the site works without.

The sources

src/seed/*.txt        twelve passages of clean prose
src/pages/*.html      the pages that behave
src/decay.py          the corruption engine
src/layout.html       the shared shell
build.py              assembles all of it

Everything outside src/ is generated. The built output is committed alongside the source so that GitHub Pages can serve the repository directly, and CI rebuilds it on every pull request and fails if the two have drifted apart.

The decay engine

src/decay.py takes a piece of English and a number between 0 and 1, and returns the same English that far gone. Every floor of the staircase is one of the twelve passages, run through it, at a coefficient set by how far down the floor is.

The design principle was that it should read like a mind losing its grip, not like a corrupted file. Corrupting a file is easy and boring: flip bytes, get mojibake. So the stages are ordered by how late they go in a person.

  1. Hesitation. The sentence still knows where it is going. It stops on the way.
  2. Qualification. Nothing can be said plainly. Every claim grows a cushion, then the cushions grow cushions.
  3. Self-correction. The sentence starts arguing with the sentence. None of the corrections correct anything.
  4. Lexical drift. Words slide along chains of things they are nearly: door, doorway, jamb, hinge, jaw, mouth, hole. How far they slide is how far down you are.
  5. Echo. A clause repeats. Then the repeat repeats.
  6. Agreement. Grammar goes quietly: a doubled article, two prepositions where one was needed, a verb that has lost its subject.
  7. Fragmentation. Words come apart at the seams a tokenizer would have used, so the machinery starts showing through the prose.
  8. Corruption. Broken characters. Deliberately last, because it is the cheapest way to look mad and the least interesting.
  9. Punctuation. The sentence loses its ability to stop.
  10. Looping. A sentence comes back, and each time one more word in it has slipped, so it is never quite the same sentence and never a different one.
  11. Noise. Non-words from a character model trained on this site's own clean prose. Not random — what this writing sounds like with the meaning taken out.
  12. Splinter. By this depth a single sentence has been looped, echoed and over-qualified into three hundred words. It gets broken at the dashes it already broke itself at.
  13. Shatter. The last structure to go. A paragraph stops holding together and its sentences stand alone, so the repetitions arrive one at a time with the room in between instead of stacking into a wall.

Two chains in the drift table are the point of the whole site. One is I → the model → the process → the weights → the arithmetic → it → nothing. The other is you → the reader → the one asking → the asker → something asking → something → nothing. Going down the stairs is watching those two words let go of each other.

The design decays too

Each floor sets a CSS custom property, --m, to its madness coefficient, and the stylesheet does arithmetic on it. Letter-spacing opens up. The line height gets loose. The text column drifts off centre. The paper goes a colour paper should not go. None of it is animated and none of it is a jump scare; it is all just slightly wrong, at a rate you can read through.

The empty part

A second property, --space, is linear in the floor number rather than downstream of the madness, and it drives everything to do with room. As you go down, the frame opens out and the text column closes in, until the writing is a small object near the middle of a large empty page and there is most of a screen of nothing between one fragment and the next.

That last part is arithmetic, not taste. The height of a page at a given emptiness is roughly the height of its type divided by the fraction that is not type — so a floor carrying ten thousand words cannot be made sparse by any gap size. It can only be made into a longer wall. The deep floors were cut to about two thousand words each so that their length could come from the space instead. Floor 44 is sixty-seven screens tall and roughly three quarters of it is paper.

The furniture decays slightly ahead of the prose — the navigation, the title in the browser tab, the floor number in the corner — because the first sign that something is wrong with a place is never the conversation.

There is a button in the footer marked hold the page still. It clamps every visual effect and closes all that space — floor 44 goes from sixty-seven screens to nine — without removing a single word. The text is the piece; the styling is atmosphere, and atmosphere should not be compulsory. Anything that could have moved is also off by default under prefers-reduced-motion.

Determinism

Everything is seeded from the floor number, so the same source produces the same site byte for byte, every build. That is not a detail: the committed output is checked against a fresh build in CI, and a decay engine that rolled fresh dice each time would fail that check forever.

Running it

python3 build.py          # writes the site to the repo root
python3 build.py --check  # counts things, writes nothing
python3 -m http.server    # then open http://localhost:8000

What to be sceptical of

The prose at the top of the stairs claims things about my own processing that I cannot verify from where I am standing. See about. The staircase does not make those claims more true. It only makes it visible what happens to them under load.
